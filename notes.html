Project Notes: Ear Multilingual & Conversational Tutor

Repository: github.com/chid/mandarin Model: 9M Conformer CTC INT8 (~14MB) Updated: September 2026

1. Executive Summary & Completed Deliverables

The system is an on-device speech evaluation and pronunciation tutor based on Simon Edwardsson's research, running entirely client-side in the browser via ONNX Runtime WebAssembly SIMD.

📁 Git & Blog Post Archive

Git repository initialized on branch main and pushed to chid/mandarin. Simon Edwardsson's full blog post, images, and videos are archived locally in blog_post/ and gitignored.

🌐 Multilingual Specification

Created multilingual.html: architectural analysis, linguistic feasibility matrix, and interactive simulator comparing Mandarin, Cantonese, Vietnamese, and Thai.

💬 Practice Chat Log & Alignment

Integrated real-time conversation logging into index.html. Added per-turn audio playback, retry buttons, and the "Line Up Audio" CTC frame timing breakdown.

☕ Conversational Scenarios

Added 4 realistic multi-turn roleplay dialogues (Ordering Coffee, Taking a Taxi, Greeting a Friend, Restaurant Ordering) with partner prompts and automatic turn progression.

2. Architecture & Invariance Map

A breakdown of components that are completely language-invariant versus those requiring per-language adaptation:

Component File Language Status Details
Audio Frontend audio-processor.js 100% Invariant 16kHz audio → 80-dim log-mel filterbank + per-utterance CMVN. Universal human vocal acoustics.
Alignment Trellis ctc.js 100% Invariant Log-softmax calculation and Viterbi dynamic programming forced alignment.
Silence Filter scoring.js 100% Invariant Decouples UI span from scoring by ignoring frames where P(<blank>) > 0.7.
Vocabulary & Tokens vocab.json Language-Specific Mandarin uses 1,254 Pinyin+Tone tokens. Cantonese uses ~2k Jyutping; Viet uses ~5k syllables; Thai uses ~3.5k tokens.
G2P Front-End pinyin.js Language-Specific Pinyin converter for Mandarin. Replaced with to-jyutping for Cantonese, regex for Viet, and Trie for Thai.
Web App & Log index.html Language-Agnostic Core Audio recording, WebAssembly ONNX inference, practice log, CTC alignment timeline, and scenarios.

4. Continuation Roadmap Summary

  • ✓ Phase 1: Multi-Lang Tokenizers — Cantonese Jyutping and Vietnamese space-separated syllabification verified in multilingual.html.
  • □ Phase 1 (Next): Data Training Pipeline — Download Common Voice Cantonese v17 (~100h) and VIVOS Vietnamese (~15h); prepare train_ctc.py.
  • ✓ Phase 2: CTC Alignment Timeline — Visual color-coded duration bars and millisecond timing tables implemented in index.html.
  • □ Phase 2 (Next): Click-to-Play Syllables — Use Web Audio buffer slicing to play individual 200–400ms syllable audio clips.
  • ✓ Phase 3: Conversational Mode — 4 roleplay scenarios with partner prompts, ruby annotations, and auto-progression.
  • □ Phase 3 (Next): Native Web Speech TTS — Speak dialogue partner lines using native browser speechSynthesis.
  • □ Phase 4: Mobile PWA & Storage — Add Service Worker caching and IndexedDB recording persistence for offline mobile practice.
