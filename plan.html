1. Syllable Audio Slice Playback (Next Task for index.html)

Using the Web Audio API to play just the specific time window (e.g. 0.48s → 0.80s) when a user clicks a syllable segment:

function playSyllableSlice(turnId, startSec, endSec) { const turn = state.chatHistory.find(t => t.id === turnId); if (!turn || !turn.audioBlob) return; const reader = new FileReader(); reader.onload = async () => { const ctx = new (AudioContext || webkitAudioContext)(); const audioBuffer = await ctx.decodeAudioData(reader.result); const source = ctx.createBufferSource(); source.buffer = audioBuffer; source.connect(ctx.destination); // Play only the syllable window with a small 20ms padding const offset = Math.max(0, startSec - 0.02); const duration = (endSec - startSec) + 0.04; source.start(0, offset, duration); }; reader.readAsArrayBuffer(turn.audioBlob); }

2. Partner Speech Synthesis (Native In-Browser TTS)

Playing the partner dialogue voice without needing an external cloud API:

function speakPartnerText(text) { if (!window.speechSynthesis) return; const utterance = new SpeechSynthesisUtterance(text); utterance.lang = 'zh-CN'; // Use 'zh-HK' for Cantonese, 'vi-VN' for Viet, 'th-TH' for Thai utterance.rate = 0.9; // Slightly slower for learners window.speechSynthesis.speak(utterance); }
